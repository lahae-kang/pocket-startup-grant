CRM 일정 연결 프로그램

Chrome 또는 Edge에서 로그인한 CRM의 미팅 목록을 읽어 지원사업 매칭보드의 스케줄에 연결합니다.

연결 프로그램 ZIP 다운로드

1. 확장 프로그램 설치

  1. ZIP 파일의 압축을 폴더에 풉니다. 이 폴더는 설치 후에도 보관해 주세요.
  2. Chrome 주소창에 chrome://extensions를 입력합니다. Edge는 edge://extensions입니다.
  3. 개발자 모드를 켠 뒤 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
  4. 압축을 푼 폴더 안에서 manifest.json이 들어 있는 폴더를 선택합니다.

2. CRM과 보드 연결

  1. 같은 브라우저 프로필에서 CRM 일정표와 매칭보드를 열고 양쪽을 새로고침합니다.
  2. CRM에 로그인하고 가져올 날짜를 표시한 뒤 약 20초 기다립니다. 일·주·월 보기 중 화면에 표시된 날짜만 전달됩니다.
  3. 보드의 스케줄 옆 CRM을 누릅니다. 확장 프로그램 연결됨과 최근 화면의 일정 개수를 확인합니다.
  4. 자동 연동을 켭니다. 본인 미팅만 원하면 담당자에 CRM에 표시되는 본인 이름을 입력합니다.
  5. 기업명이 서로 다른 항목은 기업 연결에서 연결할 기업을 선택하고 저장을 누릅니다.

동작 범위

두 탭이 열려 있으면 CRM 화면을 약 10초마다 확인합니다. 탭을 닫거나 다른 날짜를 표시하면, 보이지 않는 일정은 새로 확인할 수 없습니다. 여러 날짜를 가져오려면 CRM에서 해당 날짜 또는 주·월 보기를 표시해 주세요.

이름이 유일하게 맞는 기업만 자동 연결합니다. 수동으로 등록한 같은 기업·날짜·시간의 미팅은 중복 생성하지 않습니다.

같은 화면 범위 안에서 변경 전·후 일정이 각각 하나로 확인되면 시간을 갱신합니다. CRM이 고유 일정 번호를 화면에 제공하지 않으므로 모호한 변경이나 사라진 일정은 자동 삭제하지 않습니다. 보드 CRM 창의 화면에서 확인되지 않은 미팅에서 확인 후 숨길 수 있습니다.

연동 미팅은 Supabase의 app_state 안에 별도 행 startup-grant-board-notion-v1:crm-meetings-v1으로 저장됩니다. 기존 기업·지원사업·수동 일정 행은 이 연동 저장에서 수정하지 않습니다.

프로그램은 이 CRM과 매칭보드 주소에서만 실행됩니다. 로그인 비밀번호·쿠키·연락처를 읽지 않습니다. 기업명, 미팅일시, 담당자, 미팅 종류·장소만 처리합니다. 서버 저장 실패 문구가 보이면 Supabase의 해당 행 읽기·쓰기 권한을 확인해야 합니다.

문제 확인

확장 프로그램이 대기 중이면 CRM과 보드를 같은 브라우저 프로필에서 다시 열고 새로고침합니다. 일정 0개이면 CRM의 현재 날짜에 표시된 미팅이 있는지 확인합니다. 페이지 구성이 바뀌어 읽지 못하는 경우 자동으로 잘못된 값을 넣지 않고 대기합니다.
